# Лендінг «Стратегия управляемого роста в бизнесе» (російська версія)

Російськомовна копія лендінга `skz-gg.biznes-club-knb.com` (папка `G:Claudeskz-google`) за ТЗ від 25.09.2026. Технічна частина та сама; видимі тексти російською, приховані поля для CRM — українською, як в українській версії.

## Структура

```
index.html        — уся сторінка (тексти редагувати тут)
thank-you.html    — сторінка подяки після заявки (/thank-you)
css/styles.css    — стилі лендінгу
css/thank-you.css — стилі сторінки подяки
js/main.js        — модальна форма, слайдер, UTM/gclid, події аналітики
api/lead.js       — серверна функція Vercel: приймає заявку і пересилає її
assets/img/       — зображення
vercel.json       — налаштування Vercel
dev-server.js     — локальний перегляд без Vercel
```

## Як редагувати тексти

Відкрийте `index.html` і знайдіть потрібний блок. Кожен розділ позначено коментарем `<!-- ============ НАЗВА ============ -->`. Змініть текст, зробіть коміт і push у GitHub, і Vercel оновить сайт автоматично.

## Локальний перегляд

```bash
node dev-server.js
```

Відкрийте http://localhost:3002. Якщо змінні оточення не задані, заявки з форми виводяться в консоль.

## Публікація: GitHub → Vercel

1. Створіть репозиторій на GitHub і завантажте в нього вміст цієї папки.
2. На vercel.com: **Add New → Project → Import** цей репозиторій. Framework Preset: **Other**. Збирати нічого не потрібно.
3. **Settings → Environment Variables**: задайте, куди надходять заявки (див. нижче). Потім зробіть **Redeploy**.
4. **Settings → Domains**: підключіть домен або піддомен, `skz-gg-ru.biznes-club-knb.com`.

### Куди надходять заявки

Основний канал — **CRM NetHunt** через вебхук, так само як було налаштовано в Creatium.

| Змінна | Значення |
|---|---|
| `NETHUNT_WEBHOOK_URL` | Адреса вебхука NetHunt: `https://nethunt.com/service/automation/hooks/…` |
| `NETHUNT_AUTH` | Значення заголовка Authorization **повністю**, разом зі словом `Basic`: `Basic XXXX…` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Необов'язково. Дублює заявку в Telegram-чат менеджерів. |

> ⚠️ `NETHUNT_AUTH` — це секрет: закодовані логін і API-ключ NetHunt. Задавайте його тільки у Vercel і ніколи не записуйте в код чи GitHub. Коли перевипустите вебхук або ключ, просто оновіть змінні у Vercel і зробіть Redeploy.

Тіло запиту в NetHunt має ті самі ключі, що в конструкторі Creatium:

| Ключ | Звідки значення |
|---|---|
| `name`, `phone` | поля форми; телефон тільки цифрами, без «+» (380959782201) |
| `email` | порожнє (у формі немає email) |
| `nameform` | приховане поле `leadname`: «Заявка на безкоштовну консультацію: СКЗ новий - Гугл пошук» |
| `source` | приховане поле `source`: «Заявка на консультацію (СКЗ новий - Google)» |
| `additionally` | назва форми (яку кнопку натиснули) |
| `sitename` | адреса сторінки без UTM-міток і параметрів |
| `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `gclid` | з URL |
| `FBclid`, `Ніша`, `Lead Token` | з параметрів URL `fbclid`, `nisha`, `lead_token` |

Статичні значення `source` і `leadname` лежать прихованими полями в обох формах в `index.html`.

Якщо не налаштовано жодного каналу або NetHunt повернув помилку, форма показує відвідувачу повідомлення про помилку, тому заявка не загубиться непомітно. Подробиці помилки видно в логах функції у Vercel (**Project → Logs**).

### Аналітика

- На обох сторінках підключено той самий контейнер GTM, що й на Creatium: `GTM-WQSTVG6H`.
- Після успішної заявки відвідувача переадресовує на **сторінку подяки `/thank-you`** ([thank-you.html](thank-you.html)), як це було в Creatium.
- **Конверсія Google Ads** (`AW-16898385192/BB4oCPP66MoaEKjK4_k-`) відправляється на сторінці подяки, так само як на старій сторінці подяки. Відмінність одна: вона рахується тільки після реальної заявки. Форма ставить позначку перед переходом, і повторне відкриття чи оновлення сторінки подяки зайвої конверсії не створює.
- Перед переходом у `dataLayer` також надсилається подія `lead_form_submit` (з полем `form_name`) і викликається `fbq('track','Lead')`, якщо Meta Pixel завантажено через GTM. Якщо в GTM прив'язуєте до `lead_form_submit` щось для Google Ads, стежте, щоб та сама конверсія не рахувалася двічі: вона вже відправляється зі сторінки подяки.
- Адреса сторінки подяки задається змінною `THANK_YOU_URL` на початку [js/main.js](js/main.js).
